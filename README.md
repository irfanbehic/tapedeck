# Tapedeck

The public website for **Tapedeck**, an iOS voice recorder that never loses your recording.

Live at **https://irfanbehic.github.io/tapedeck/**

## Support

Found a bug, or something in the app is not behaving? [Open an issue](https://github.com/irfanbehic/tapedeck/issues/new), or write to irfanbehic@gmail.com.

## About this repository

Static HTML and CSS, served by GitHub Pages from the `main` branch. No build step, no
dependencies. Colours, type and the glass recipe are lifted from the app's own design system,
so the site and the app read as the same thing.

```
index.html        landing page
privacy/          privacy policy
terms/            terms of use
support/          support and FAQ
assets/           style.css, site.js, app icon
```

The app's source is not in this repository.
